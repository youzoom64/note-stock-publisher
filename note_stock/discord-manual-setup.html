Discordを手動で設定する手順

やっぱり自動で設定する

1. Discordで専用アプリを作成する

Discord開発者ポータルを開くを押し、ご自身のDiscordアカウントでログインします。「新しいアプリケーション（New Application）」を押し、名前を「note管理」にします。開発者向けの規約を確認して作成してください。所有者はご自身のアカウントを選びます。

2. サーバーに導入できるように設定する

左の「インストール（Installation）」で「ギルドのインストール（Guild Install）」だけを有効にし、「インストールリンク（Install Link）」を「なし（None）」にして保存します。

左の「Bot」で「公開Bot（Public Bot）」をオフにし、「OAuth2コード付与を要求（Requires OAuth2 Code Grant）」もオフにします。「変更を保存」が表示されたら保存してください。

3. Botを導入する

左の「OAuth2」にある「URL Generator」で bot と applications.commands を選びます。Botの権限は次の6件です。

  • チャンネルの管理（Manage Channels）
  • チャンネルを見る（View Channels）
  • メッセージを送信（Send Messages）
  • リンクの埋め込み（Embed Links）
  • ファイルを添付（Attach Files）
  • メッセージ履歴を読む（Read Message History）

生成されたURLをブラウザーで開き、ご自身が管理できるサーバーを選んで認証します。サーバーを新しく作る場合は、先にDiscordのサーバー一覧の「＋」で作成してください。

4. 接続情報をnoteストックに入れる

  1. 開発者ポータルの「Bot」で「トークンをリセット（Reset Token）」を押し、本人認証を済ませます。表示された値をnoteストックの「Botトークン」欄に貼り付けます。トークンはこの欄だけに貼り付けてください。
  2. Discordで「ユーザー設定」→「詳細設定」→「開発者モード」をオンにします。導入先のサーバーアイコンを右クリックし、「サーバーIDをコピー」を押して、noteストックの「導入先のサーバーID」欄に貼り付けます。
  3. noteストックで「保存して接続」を押します。導入が確認できると「note管理」チャンネルと操作メニューが準備されます。
